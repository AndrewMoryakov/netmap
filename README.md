# netmap — карта сети Windows

Локальная интерактивная страница, которая показывает, **какая программа через какой сетевой интерфейс (включая VPN и прокси-туннели) куда отправляет трафик** — и помогает понять, почему несколько VPN на одной машине мешают друг другу.

*English: a local, read-only web map for Windows that shows which process talks through which network adapter (VPN/TUN/proxy included) and where it goes. Russian UI.*

```
процессы  →  интерфейсы (метрика, DNS, скорость)  →  куда уходит трафик
```

## Что умеет

- **Карта «процесс → интерфейс → назначение»**: адаптеры, маршруты, DNS, локальные прокси, соединения по процессам (число соединений — толщина линии).
- **Знает про** Happ, Clash Verge, Cisco AnyConnect, Tailscale, NetBird (со своими сборщиками данных); WARP, GlobalProtect, FortiClient, ZeroTier, OpenVPN, WireGuard, WSL, Hyper-V показывает как универсальные виды. Список и цвета — в `netmap.config.json`.
- **Состояние узлов**: цветная точка в заголовке (норма / внимание / проблема / отключён), замечания сверху (например, «два TUN одновременно», «DNS перехвачен», «домен сервера попадает под NRPT-правило»).
- **Живой трафик**: скорость ↓/↑ по адаптерам, мини-график, бегущие штрихи по линиям «интерфейс → назначение».
- **Подсветка изменений**: узел или линия мигает 8 секунд, если что-то изменилось (адаптер поднялся/упал, процесс сменил интерфейс, сменилось состояние AnyConnect и т. д.); подсказка говорит, что именно.
- **Монитор и журнал**: фоновые пробы DNS/ping, журнал событий (`events.jsonl`).
- **Проверки по кнопке**: опрос каждого DNS-сервера, внешний IP (напрямую и через локальные прокси), «Путь» до домена/IP.
- **«План…»**: составляет *план*, как направить адрес, подсеть или программу через другой интерфейс (перетащите узел на интерфейс). Выдаёт скрипты применения и отката, **сам ничего не применяет**.
- **«Связи»**: реестр ваших намерений (`netmap.links.json`), статусы «не применена / действует / отмечена вручную / расходится», классификация маршрутов (были по умолчанию / появились после запуска / мои).

## Принципы безопасности

- **Только чтение.** Карта ничего не меняет в системе: ни маршруты, ни `hosts`, ни настройки VPN. Все изменения — скриптами из «Плана», которые вы копируете и запускаете сами.
- Слушает **только `127.0.0.1`** (порт 47900, если занят — до 47909), наружу ничего не отправляет. Исключение — кнопки проверок (запрос на `cloudflare.com` для внешнего IP и DNS-пробы), только по вашему нажатию.
- Защита локального API: проверка заголовка `Host`, обязательный заголовок `X-NetMap` (простой запрос с чужого сайта не пройдёт), запись — только `POST` с `Content-Type: application/json`.
- Вводимые адреса и подсети валидируются; подсети шире `/8` отклоняются.

## Требования

- Windows 10/11.
- **PowerShell 7** (`pwsh`). При запуске из Windows PowerShell 5.1 скрипт сам перезапустится в `pwsh`, если он установлен.
- Браузер.
- Права администратора не нужны для карты; они понадобятся только для выполнения скриптов из «Плана» (маршруты).

## Запуск

```
netmap.cmd
```

или

```
pwsh -NoProfile -ExecutionPolicy Bypass -File netmap.ps1 [-Port 47900] [-NoBrowser]
```

Откроется `http://127.0.0.1:47900/`. Остановить — закрыть окно консоли (Ctrl+C).

Первый сбор данных занимает до 20 секунд, дальше страница обновляется каждые 5 секунд (можно отключить флажком «авто»). Флажок «все процессы» показывает на карте каждый процесс, а не 14 самых активных.

## Настройка

Всё, что карта «узнаёт», описано в `netmap.config.json` (правится без изменения кода, после правки перезапустите карту):

- `adapterKinds` — виды адаптеров: регулярные выражения по имени/описанию, цвет, подпись, признак TUN/VPN. Порядок значим: побеждает первое совпадение.
- `processes` — регулярные выражения для процессов прокси, Happ, Clash.
- `paths` — где искать `routing.json` Happ, настройки Clash Verge, `vpncli` AnyConnect, `tailscale.exe`.
- `localProxyPorts`, `hotspotGatewayRx`, `skipDnsServersRx`, `probes`.

При старте конфиг проверяется; ошибка (битый JSON, неверное регулярное выражение, дубль, зарезервированное имя) сообщается понятным текстом.

## Файлы

| Файл | Назначение |
|---|---|
| `netmap.ps1` | сервер (HTTP на loopback), сбор данных, планы и реестр связей |
| `netmap-monitor.ps1` | фоновый монитор (DNS, ping, события) |
| `index.html` | вся страница (карта, вкладки, «План…», «Связи») |
| `netmap.config.json` | настройки |
| `netmap.cmd` | запуск двойным щелчком |

Создаются при работе рядом со скриптами и не попадают в git (`.gitignore`): `netmap.log`, `events.jsonl`, `netmap.links.json`.

## Ограничения

- Только Windows + PowerShell 7; на других машинах и конфигурациях проверена мало.
- Для программ вне списка (без собственного сборщика) карта покажет адаптер, маршруты и узел назначения, но не данные самой программы.
- Скорость считается по адаптерам, а не по процессам (средствами Windows без ETW это не получить).
- Привязка соединения к интерфейсу идёт по локальному адресу сокета; UDP/QUIC-цепочки видны хуже TCP.
- Применение маршрутов кнопкой с автооткатом пока не реализовано — только копирование скриптов.
